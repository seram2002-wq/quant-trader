# quant-trader — 실시간 전략 시험 (모의투자 + 가상 매매)

직접 만든 매매 전략을 실시간 시세로 시험하는 프로그램입니다. 전략마다
**모의투자 계좌에 실제로 주문**하거나 **가상 장부에서만** 사고팔도록 정할 수
있고, 여러 전략을 동시에 돌립니다. 시세와 주문은 한국투자증권 Open API
(모의투자 서버)를 씁니다.

『파이썬 증권 데이터 분석』 실습 저장소(`quant_실습`) 8장 자동매매의 틀(증권사
연결, 장중 감시, 알림, 시간표)에서 출발해 새로 만들었습니다.

- 결과 보고서와 일지는 각자 컴퓨터의 `results/`에 생기고, 깃에는 올리지 않습니다
  (`.gitignore`). 매매 기록이 공개 저장소에 남지 않고, 포크해 간 사람은 빈 상태에서
  자기 결과를 쌓습니다. 일지는 직접 쓴 기록이라 가끔 다른 곳에 백업해 두세요.

## 목표와 운영 방식

여러 전략을 시험해서, 결과가 좋은 로직을 그대로 실전 매매에 옮기는 것이 목표입니다.

| 계좌 | 역할 | 돌리는 것 |
|---|---|---|
| 모의투자 | 운영 후보 (실전 직전 단계) | 지금 가장 믿을 만한 로직 하나 |
| 가상 장부 | 실험실 | 새 전략, 기존 전략의 변형 |
| 가상 장부 (그림자) | 비교 기준 | 모의투자 로직을 가상으로도 똑같이 |

가상에서 좋은 결과가 나온 로직을 모의투자로 올리고, 모의투자에서 검증된 로직을
실전으로 옮깁니다. 가상 장부는 체결을 낙관적으로 가정하므로, 실험 전략은 그림자
장부와 비교하고, 그림자와 모의투자의 차이로 가상 장부가 얼마나 낙관적인지 잽니다.

## 현재 돌리는 전략

| 전략 | 버전 | 계좌 | 슬랙 채널 | 메시지 앞머리 |
|---|---|---|---|---|
| 장 마감 반전 | v1 | 모의투자 (실제 주문) | `#seram-quant` | `[모의·장 마감 반전 v1]` |
| 장 마감 반전 (그림자) | v1 | 가상 장부 | `#paper-trading` | `[가상·장 마감 반전 v1]` |
| 장 마감 반전 + 악재 공시 필터 (실험) | v2 | 가상 장부 | `#paper-trading` | `[가상·장 마감 반전 v2]` |
| 밤사이 보유 (참고, 2 ~ 3주) | v0 | 가상 장부 | `#paper-trading` | `[가상·밤사이 보유 v0]` |

실험 전략은 백테스트 기준을 통과한 것만 가상 장부에 올리는 것이 원칙입니다 (아래
"실험 전략 채택 기준"). 멀티팩터와 VWAP 추세는 2026-11-18 백테스트에서 기준을 넘지
못해 보류 중이고, `config.py`에서 주석 처리되어 있습니다. 밤사이 보유는 효과 자체는
뚜렷하지만 실제 ETF 가격으로 기준 통과를 아직 확인하지 못한 상태에서, 장 마감 반전과
비교하려고 v0로 먼저 돌립니다.

### 실험 전략 채택 기준

- 탐색 구간(2016-04 ~ 2019)에서 조합을 고르고, 검증 구간(2020 ~ 2024)으로 확인
- (2026-11-19 변경) 두 구간 모두 코스피 이상, 두 구간 모두 최대 낙폭이 코스피보다 작고,
  검증 구간은 코스피 + 5%p 이상일 것. 처음 기준(두 구간 모두 + 5%p)은 코스피가 지루했던
  탐색 구간에서 너무 높아서 바꿈. 결과를 본 뒤 바꾼 기준이라, 통과한 전략도 가상 장부에서
  몇 주 확인한 뒤 판단
- 2025년 이후는 마지막 확인용으로 남겨 두고, 규칙을 고르는 동안 보지 않음
- 비용(수수료, 매도 세금 0.20%, 슬리피지), 상장폐지 종목, 데이터가 늦게 오는 것(2거래일)까지 반영

전략 이름과 버전은 따로 셉니다. 같은 전략의 규칙을 바꾸면 그 전략의 버전만
올라갑니다 (예: 장 마감 반전 v2). 버전은 매매 기록과 보고서에 남습니다.

### 장 마감 반전 v1 (`strategies/close_reversal.py`)

장 마감 전에 그날 많이 밀린 종목을 사서 장 마감 직전에 팝니다.

- 근거: 「한국 주식시장의 일중 반전 현상: KOSPI를 중심으로」(KAIST 석사학위논문,
  2021). 2011~2020년 KOSPI 종목에서 장 초반 30분 모멘텀은 나타나지 않고, 장 마감
  1시간~30분 전 구간에서 반전(밀린 종목이 되돌아옴)이 나타남. 반전은 거래량이
  적고 시가총액이 작은 종목일수록 강함

| 항목 | 규칙 |
|---|---|
| 종목 범위 | 거래대금 상위 보통주 30개, ETF·ETN·레버리지·인버스 제외 (10분마다 갱신) |
| 매수 시간 | 14:30 ~ 15:00 동안 계속 감시 |
| 매수 조건 | 오늘 시가 대비 -2% 이하 (-15%보다 많이 빠진 종목 제외) |
| 고르는 순서 | 조건을 만족한 종목 중 시가 대비 가장 많이 떨어진 순, 최대 4종목 |
| 주문 | 최유리지정가 매수, 덜 체결되면 잔량 취소. 15:15 시장가 매도 |
| 자금 | 1,000만 원 배정, 종목당 24% (계좌에 더 있어도 이만큼만 사용) |
| 익절·손절 | 없음 (연구 방식대로 장 마감까지 보유) |

### 실험: 장 마감 반전 v2 — 악재 공시 필터 (`strategies/close_reversal.py`의 `CloseReversalV2`)

v1과 모든 규칙이 같고, 매수 후보 중 악재 공시가 난 종목만 뺍니다. 한 가지만 바꿔야 차이가
필터 때문인지 알 수 있어서입니다. 2026-11-20부터 가상 장부에서 v1 그림자와 나란히 돌립니다.

| 항목 | 규칙 |
|---|---|
| 보는 공시 | 직전 거래일 15:30 이후 처음 본 공시 + 그 뒤 오늘까지 (전날 장중 공시는 이미 주가에 반영됐다고 봄). 거래일은 분봉이 저장된 날로 판단하므로 프로그램을 안 돌린 거래일은 휴장일처럼 다뤄짐 |
| 악재 | 유상증자·전환사채·신주인수권부사채·교환사채 발행, 감자, 횡령·배임, 불성실공시법인, 상장적격성, 관리종목, 투자주의환기, 매매거래정지, 회생절차, 파산, 공급계약해지, 영업정지, 소송 (`trader/disclosures.py`) |
| 제목 비교 | 공백, `[기재정정]` 같은 머리말, 가운뎃점을 지운 뒤 비교. 자회사·종속회사 공시와 해제 공시(매매거래정지해제 등)는 악재로 보지 않음. 조회공시요구·풍문 해명 같은 애매한 공시는 거르지 않고 기록만 |
| 빈자리 | 하락 조건(시가 대비 -2% 이하)을 만족한 다음 순위 후보로 채움. v1과 보유 수를 같게 |
| 최신 공시 | 매수 시간에 최대 1분에 한 번 DART에서 새 공시 확인 |
| 감시 종목 | v1과 같은 목록을 같이 씀 (`universe_key`) |
| 장부 | `data/paper_close_reversal_v2/` (`config.py`의 `'book'`) |

- 슬랙에 "제외 : 종목코드 악재 공시 (분류: 키워드) 제목, 처음 본 시각"이 남습니다. 같은 날 그림자(v1)가
  그 종목을 샀다면, 필터가 손실을 피했는지 거래 단위로 바로 비교할 수 있습니다
- 판단: 필터가 10번 이상 걸릴 때까지 (최소 4주). 걸린 종목의 v1 결과가 평균 마이너스이고 v2 손익이
  v1 이상이면 모의투자를 v2로 바꿈
- 공시 저장을 시작한 첫날은 전날 장중 공시도 "15:30 이후"로 잡혀 과하게 걸러질 수 있어, 제외 알림에
  "전날 장중 공시일 수 있음"을 붙입니다

### 그림자 기록: 뉴스 판정 (`run.py`의 `NewsCheck`, `trader/news_filter.py`)

매매에는 전혀 쓰지 않고, 뉴스 제목 판정 결과만 `data/news/YYYYMMDD.csv`에 쌓습니다. 몇 주 쌓인 뒤
v1·v2 거래와 비교해서 쓸모가 있을 때만 필터로 올립니다. `.env`에 네이버 검색 API 키가 없으면 꺼집니다.

| 항목 | 규칙 |
|---|---|
| 보는 종목 | 평소 20분마다 거래대금 상위 30종목 + 보유 종목. 마감 45분 전 ~ 30분 전(평소 14:45 ~ 15:00)에는 3분마다 각 전략의 매수 후보 상위 5종목만 |
| 판정 (제목만) | 악재 / 예외(악재 키워드 + 무혐의·해제·기각·철회 등) / 호재 / 혼재 / 중립. 키워드 목록은 `trader/news_filter.py` |
| 저장 | 직전 거래일 장 마감 뒤에 나온 기사만, (종목, 링크)마다 한 번. 기사 시각(`pub_time`)도 저장 |
| 매매 지연 | 네이버 검색은 따로 스레드에서. 매매 흐름에서는 20분마다 거래대금 순위 조회 1번만 |

### 참고: 밤사이 보유 v0 (`strategies/overnight_etf.py`)

실제 KODEX 200 일봉 백테스트에서 경계선 탈락(왕복 0.03%: 탐색 +3.0%, 검증 +6.3%)했고, 실제 계좌
ETF 수수료(0.0146527%, 왕복 약 0.029%)로는 통과 조건(0.02% 이하)에 못 미칩니다. 2026-11-20부터
2 ~ 3주만 동시호가 체결을 흉내 내(슬리피지 0) 실제 하루하루 결과를 참고로 보고 정리합니다.

장 마감 직전에 KODEX 200을 사서 다음 날 장 시작 직후에 팝니다. 장중에는 들고 있지 않습니다.

- 근거: 한국 시장은 수익 대부분이 밤사이(전일 종가 → 오늘 시가)에 나고 장중은
  마이너스인 경향이 오래 이어짐 (Cliff·Cooper·Gulen 2008 등 여러 시장에서 보고)
- 이 저장소의 확인: 코스피 전 종목 2011 ~ 2026 밤사이 연 +21.7% (t 5.77), 장중 -12.7%.
  코스피200 지수 2005 ~ 2026 밤사이 플러스인 해 19/22. KODEX 200 실제 가격(최근 2년)은 지수의 약 4/5
- 매일 왕복이라 비용이 결과를 좌우함. 지수 기준 비용 0.03%에서 탐색 연 +5.7%, 검증 +12.6%.
  실제 ETF로는 탐색 구간이 기준에 못 미칠 수 있어 v0. KODEX 200 일봉으로 다시 확인할 것
- 장 마감 반전(오후 30분 ~ 45분 보유)과 시간대가 겹치지 않아, 같은 "장 마감 무렵" 계열끼리 비교하기 좋음

| 항목 | 규칙 |
|---|---|
| 대상 | KODEX 200 |
| 매수 | 15:18 ~ 15:20, 그때 가격 |
| 매도 | 다음 날 09:00 장 시작 직후 (**프로그램을 09:00 전에 켜 둘 것**) |
| 자금 | 가상 1,000만 원, 95% |
| 체결 가정 | 슬리피지 0 (2026-11-20부터, 동시호가 체결 흉내. 전략별로 `config.py`의 `slippage`), 수수료 0.015%, 매도 세금 없음 |

### 보류: 멀티팩터 v0 (`strategies/multi_factor.py`)

**2026-11-18 백테스트 결과 기준 미달로 보류.** 자세한 표는
[docs/backtest_summary.md](docs/backtest_summary.md)에 있습니다.

- 아래 규칙(거래대금 상위 60개 중 모멘텀 상위)은 2012~2024년 연 -36%. 거래대금
  순위로 고르면 테마주·과열주가 걸려서 며칠 보유하는 동안 크게 빠짐
  (2012년 대선 테마주, 2023년 영풍제지 등)
- 시가총액 상위 200~300개로 바꾸고 가격(모멘텀, 저변동성, 52주 고가, 소형 등)과
  DART 재무(PBR, PER, ROE, 영업이익/자산, 부채비율) 항목을 조합해 56가지를 시험.
  두 구간을 모두 통과한 조합은 없었음
- 시가총액 상위 200개 안에서 각 항목의 5분위 수익률 차이(2016~2024)는 모두
  통계적으로 의미 없는 수준(t값 절댓값 1 미만). 이 기간 한국 대형주에서는
  단일 팩터의 효과가 뚜렷하지 않았음
- 업종 중립(업종 안에서 순위)으로 다시 시험해도 통과 0개. 다만 모멘텀 + 저변동성은
  크게 나아짐 (검증 구간 중앙값 연 +6.8%, 기준까지 약 0.2%p와 낙폭 1%p 차이)
- 과거 맞춤 점검: 한 설정이 아니라 범위·종목 수 6개 설정의 중앙값으로 판단. 탐색
  구간 최고 설정이 검증에서 무너지는 경우가 많았음 (예: +4.8% → -3.8%)
- 다음 후보: 외국인·기관 수급(한국거래소 계정 필요), 배당, 모멘텀 + 저변동성(업종 중립)

아래는 처음 만든 v0 규칙입니다 (기록용).

하루 한 번 장 마감 직전에 종목마다 점수를 매겨 상위 종목을 사고, **다음 날까지
들고 갑니다**. 순위가 많이 밀린 종목만 바꿔서 매매 횟수와 세금을 줄입니다.
장중 계속 감시하지 않아서 모의투자로 옮기기 쉬운 구조입니다.

- 출발점: 국면 판단 → 유동성 필터 → 여러 팩터 순위 합산이라는 일반적인 롱온리
  팩터 투자 틀. 공매도 없이 하락장을 버티도록 약세 국면에는 보유 수를 줄임
- 가중치와 숫자는 검증된 값이 아니라 출발점입니다. 백테스트로 정한 뒤 v1로 올립니다

| 항목 | 규칙 |
|---|---|
| 종목 범위 | 코스피·코스닥 거래대금 상위 각 30개 + 보유 종목. ETF·ETN, 우선주, 스팩 제외. 20일 평균 거래대금 50억 원 미만 제외 |
| 점수 | 모멘텀 40% (20일 수익률 ÷ 변동성), 외국인 수급 35% (5일 순매수 금액 ÷ 평균 거래대금), 단기 반전 25% (3일 수익률 반대). 각각 순위를 0~1로 바꿔 합산 |
| 국면 | KODEX 200이 20일 이동평균 위면 최대 5종목, 아래면 최대 2종목 |
| 교체 | 매일 15:05. 보유 종목은 10위 안이면 유지, 밖이면 매도. 빈자리는 5위 안에서 채움 |
| 매수 제외 | 관리종목, 투자경고·투자위험, 거래정지 |
| 보유 | 15:15 일괄 매도 없이 다음 날까지 |
| 자금 | 가상 1,000만 원, 종목당 19% |

- 데이터는 모두 한국투자증권 API에서 받습니다 (일별 시세 약 30일, 수정주가).
  기관 순매수는 이 API에 없어서 외국인만 씁니다. 외국인 값이 오지 않으면 수급
  항목을 빼고 나머지 둘로 계산합니다
- 프로그램을 매일 켜야 교체가 일어납니다. 켜지 않은 날은 보유 종목을 그대로 들고 갑니다
- `python run.py --check`로 지금 시점의 점수표와 들고 갈 종목을 미리 볼 수 있습니다

### 실험 후보: VWAP 추세 v1 (`strategies/vwap_trend.py`, 지금은 실행 안 함)

장 시작부터 끝까지, 가격이 그날의 거래량 가중 평균가(VWAP) 위에 있는 쪽을
보유합니다.

- 근거: Zarattini·Aziz, "Volume Weighted Average Price (VWAP): The Holy Grail
  for Day Trading Systems" (2023). 미국 QQQ에서 VWAP 위면 매수, 아래면 매도하는
  규칙이 2018~2023년 수수료 차감 후 샤프 2.1, 최대낙폭 9.4%. 실무 연구이며 미국
  시장 결과라 국내에서는 검증이 필요함
- 국내 개인은 공매도가 어려워서, 하락 쪽은 KODEX 인버스를 사는 것으로 대신함

| 항목 | 규칙 |
|---|---|
| 대상 | KODEX 200, KODEX 인버스 |
| 매수 | 종목 가격이 그 종목의 VWAP보다 0.1% 이상 위 |
| 매도 | VWAP보다 0.1% 이상 아래 (하루에 여러 번 사고팔 수 있음) |
| 시간 | 09:05 ~ 15:00 판단, 15:15 일괄 매도 |
| 자금 | 가상 1,000만 원, 한 번에 95%, 최대 1종목 |

0.1% 여유폭은 VWAP 근처에서 잦은 매매를 줄이려고 넣은 값으로, 연구에는 없습니다.

**2026-11-18 국내 백테스트 (야후 파이낸스 장중 시세, 비용 포함): 보류**

| 데이터 | 기간 | VWAP 추세 | KODEX 200 보유 |
|---|---|---|---|
| 1시간봉 | 2023-11 ~ 2026-11 (2년) | 누적 -59%, 최대낙폭 -63% | 누적 +139% |
| 5분봉 | 2026-08 ~ 2026-11 (60일) | 누적 -20%, 최대낙폭 -27% | 누적 -28% |

비용을 0으로 놓아도 1시간봉 2년 연 +2.8%로, 지수 보유보다 크게 뒤짐. 하루 평균
1~4번 사고팔아 비용 부담이 크고, 미국 QQQ에서의 결과가 국내 ETF에서는 재현되지
않았음. 5분봉은 60일뿐이라 참고용.

cd C:\workspaces\quant\quant-trader

### 매일

```
.venv\Scripts\activate
python run.py --check     (선택) 지금 시점의 전략별 판단만 출력, 주문 안 함
python run.py             장중 실행, 마감 10분 전(평소 15:20)에 스스로 종료
python report.py          장 마감 후 results 보고서 갱신
```

- **09:00 전에** 켭니다. 밤사이 보유가 전날 산 KODEX 200을 09:00에 팔고, 장 마감 반전은 14:30부터 판단합니다.
- 시각은 모두 그날 장 시간 기준입니다 (`trader/market.py`). 전략과 `config.py`에는 "개장 N분 뒤(0 이상)" 또는
  "마감 N분 전(음수)"으로 적습니다. 예: 장 마감 반전 매수 `(-60, -30)`, 일괄 매도 `EXIT_TIME = -15`.
  수능 날처럼 장 시간이 다른 날은 `config.py`의 `SPECIAL_HOURS`에 `'YYYYMMDD': (개장, 마감)`만 적으면
  매수·매도·종료·분봉 저장·공시 필터의 "전날 장 마감 뒤" 기준이 같이 밀립니다. 거래소 공지를 보고 미리 적어 둡니다.
- 장 마감 후 `python report.py`로 `results/`에 전략별 보고서를 만들고, 관찰한 것은
  `results/journal.md`에 적습니다. 처음에는 `results/` 폴더가 없으니 그대로 실행하면 생깁니다.
- `report.py`는 quantstats가 설치되어 있으면(`pip install -r requirements.txt`) 장부마다
  성과 분석 보고서 `results/<장부>_tearsheet.html`(샤프, 소르티노, 최대 낙폭, 월별 수익,
  KODEX 200 비교)와 장부끼리 비교표 `results/comparison.md`도 만든다. 거래일 5일 이상부터.
  KODEX 200 비교는 `tools/fetch_research_data.py`로 일봉을 받아 둔 뒤에 나온다
- 장부는 파일에 저장되므로 껐다 켜도 이어집니다. `Ctrl+C`로 중단하면 모의투자
  계좌의 보유 종목은 자동으로 팔리지 않으니 직접 확인합니다.

### 전략 추가와 버전 관리

- 새 전략: `strategies/`에 파일을 만들어 `Strategy`를 상속하고, `config.py`의
  `STRATEGIES`에 한 줄 추가합니다.
- 규칙 변경: 전략 파일의 `VERSION`을 올리고, 무엇을 왜 바꿨는지 일지에 적습니다.
  규칙은 정한 기간(예: 4주) 동안 바꾸지 않고 결과를 모은 뒤 판단합니다.
- 모의투자 계좌에는 운영 후보 로직 하나만 둡니다. 실험 전략은 가상 장부로 돌립니다.

| 전략 메서드 | 역할 |
|---|---|
| `universe(client)` | 감시할 종목. 조회 실패 시 실행기가 이전 목록을 유지 |
| `prepare(client, code, today)` | 하루 한 번 종목별 판단 값 계산 (선택) |
| `should_buy(info, quote)` | 매수 신호면 이유, 아니면 None |
| `pick(candidates)` | 여러 후보 중 사는 순서 (기본은 감시 순서) |
| `should_sell(info, position, quote)` | 장중 매도 신호 (15:15 일괄 매도는 실행기가 처리) |
| `buy_window`, `allow_reentry`, `intraday_exit` | 매수 시간, 같은 날 재매수 허용, 장중 매도 조건 여부 |
| `rebalance_time`, `targets(client, holdings, max_positions)` | 종목 교체형 전략: 하루 한 번 이 시각에 들고 갈 종목 목록을 돌려주면, 실행기가 목록에 없는 보유 종목을 팔고 새 종목을 산다 (`should_buy` 대신) |
| `hold_overnight` | True면 15:15 일괄 매도를 하지 않고 다음 날까지 보유 |

`quote`에는 현재가, 시가, 고가, 저가, 등락률, 거래량, 거래대금, VWAP이 들어 있습니다.

| 항목 | 가상 장부 | 모의투자 |
|---|---|---|
| 체결 수량 | 예산 안에서 전부 체결로 가정 | 계좌에서 확인한 실제 체결 수량 |
| 체결가 | 현재가 ± 0.05% (`SLIPPAGE`) | 주문 체결 조회 값 (안 되면 잔고 평균가 또는 주문 직전 현재가) |
| 수수료 | 0.015% (`FEE_RATE`) | 같은 값으로 추정 |
| 매도 세금 | 일반 주식 0.20%, ETF 0 (`STOCK_SELL_TAX`) | 같은 값으로 추정 |

수수료와 세율은 임시값이라 실전 전에 실제 값을 확인해야 합니다. 가상 장부는
호가 물량과 일부 체결을 재현하지 않으므로 실제보다 결과가 조금 좋게 나옵니다.

## 연결과 오류 처리

- 같은 종목의 현재가는 3초 안에는 다시 조회하지 않고 전략끼리 같이 씁니다.
- 조회 중 연결이 끊기면 새 연결로 다시 조회합니다. 호출 제한 오류도 잠시 뒤 다시 시도합니다.
- 주문은 자동으로 다시 보내지 않습니다. 응답 없이 끊기면 잔고로 체결 여부를 확인합니다.
- 한 전략에서 오류가 나도 다른 전략은 계속 돕니다. 시작에 실패한 전략은 그날 빠집니다.
